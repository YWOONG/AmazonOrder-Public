# AmazonOrderManager

Windows x64용 AmazonOrderManager 공식 배포 저장소입니다.

## 설치

[최신 릴리스](https://github.com/YWOONG/AmazonOrder-Public/releases/latest)에서 `AmazonOrderManager-windows-x64.zip`을 받아 압축을 풀고 `Start-AmazonOrderManager.cmd`를 실행하세요. 이 시작 파일은 업데이트 도중 전원이 꺼진 경우에도 먼저 이전 버전을 복구한 후 앱을 엽니다. EXE와 `_internal` 폴더, 시작·복구 파일을 함께 유지해야 합니다.

## 자동 업데이트

0.2.0부터 앱을 실행할 때 새 정식 릴리스를 확인하고 자동으로 다운로드합니다. 다운로드가 완료되면 앱을 종료한 뒤 업데이트가 적용됩니다. 다음 실행부터 새 버전을 사용합니다. 옵션 → 프로그램 업데이트에서 현재 버전, 진행 상태와 오류를 확인하고 다시 시도할 수 있습니다.

주문 데이터와 설정은 유지합니다. 적용 중 오류가 발생하면 이전 프로그램 파일을 복구합니다. 인터넷 연결이 없으면 현재 버전을 계속 사용할 수 있습니다. 기존 0.1.0 EXE에는 업데이트 기능이 없으므로 최초 한 번은 새 ZIP으로 교체해야 합니다.

## 릴리스 파일

각 정식 릴리스에는 다음 두 파일이 필요합니다.

- `AmazonOrderManager-windows-x64.zip`: EXE와 전체 런타임
- `update-manifest.json`: 버전, ZIP 파일명, 크기와 SHA256

태그는 `v0.2.0` 형식을 사용하며 EXE에 포함된 버전과 같아야 합니다. 태그나 릴리스 제목만 등록하면 업데이트되지 않습니다. 릴리스는 두 파일을 모두 올린 후 게시하세요. 임시 릴리스와 사전 릴리스는 자동 업데이트 대상에서 제외됩니다.

이 저장소는 배포용입니다. 프로그램 소스와 사용자의 주문·계정 데이터는 포함하지 않습니다.
